# ADR 0003: Diagrams rendered in claude-code-skills

## Status

Accepted (commit `511c887`, 2026-11-14).

## Context

The README shows one diagram per skill. The owner's other skill repository already has a diagram renderer with house rules checked by assertions.

## Decision

The SVG files are generated by `tools/render_diagrams.py` in the claude-code-skills repository and committed here under `docs/diagrams/`. This repository has no renderer.

## Consequences

- One renderer keeps the diagrams of both repositories in one style.
- A change of a skill needs a run of the renderer in the other repository and a copy of the SVG files.

## Evidence

- Commit `511c887` "Add a diagram for each skill".
- `README.md`: "The diagrams are generated by `tools/render_diagrams.py` in claude-code-skills".
